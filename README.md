# 전통시장 환급행사 스태프 관리 시스템

전통시장 환급행사 스태프들의 업무를 효율적으로 관리하기 위한 웹 애플리케이션입니다.

## 🚀 주요 기능

### 스태프 기능
- **간단한 로그인**: 이름만 입력하면 자동으로 계정 생성/로그인
- **배정된 점포 확인**: 자신에게 할당된 점포 목록 확인
- **체크리스트 관리**: 각 점포별 체크 항목 확인 및 체크
- **메모 기능**: 각 체크 항목에 메모 추가 가능
- **지도 링크**: 각 점포의 위치를 지도에서 바로 확인

### 관리자 기능
- **점포 관리**: 44개 점포 정보 추가 및 관리
- **체크 항목 관리**: 공통 체크리스트 항목 관리
- **스태프 할당**: 점포를 스태프에게 할당
- **진행 상황 확인**: 전체 점포 및 스태프 현황 확인

## 📦 기술 스택

- **Frontend**: Next.js 16 (App Router), React 19, TailwindCSS
- **Backend**: Next.js API Routes
- **Database**: SQLite + Prisma ORM
- **인증**: 쿠키 기반 세션

## 🛠️ 설치 및 실행

### 1. 의존성 설치 (이미 완료됨)
```bash
npm install
```

### 2. 데이터베이스 설정 (이미 완료됨)
```bash
# Prisma 마이그레이션 실행
npx prisma migrate dev

# Prisma Client 생성
npx prisma generate
```

### 3. 개발 서버 실행 ✅ 현재 실행 중!
```bash
npm run dev
```

**서버가 실행 중입니다!** 
- 로컬: http://localhost:3000
- 네트워크: http://192.168.45.203:3000

## 🎯 빠른 시작 가이드

### 첫 사용 시 설정 순서

1. **관리자 페이지 접속**
   - http://localhost:3000/admin 으로 접속

2. **체크 항목 추가** (예시)
   - "환급 안내 포스터 부착 확인" (카테고리: 사전 준비)
   - "환급 신청서 비치 확인" (카테고리: 사전 준비)
   - "점주 교육 완료 확인" (카테고리: 사전 준비)
   - "영업 시간 확인" (카테고리: 현장 확인)
   - "QR코드 작동 확인" (카테고리: 현장 확인)

3. **점포 추가** (1번부터 44번까지)
   - 점포 번호: 1-44
   - 점포명: 실제 점포 이름
   - 주소: 실제 주소
   - 지도 링크: 네이버 지도 또는 카카오맵 링크
   - 카테고리: 식품, 의류, 잡화 등

4. **스태프 로그인**
   - 메인 페이지(http://localhost:3000)에서 이름 입력
   - 처음 입력하는 이름이면 자동으로 계정 생성

5. **점포 할당**
   - 관리자 페이지에서 스태프에게 점포 할당
   - 각 스태프는 자신에게 할당된 점포만 볼 수 있음

6. **체크리스트 사용**
   - 스태프가 대시보드에서 점포 클릭
   - 체크 항목 확인 및 체크
   - 필요시 메모 추가

## 📱 사용 방법

### 스태프 사용자

1. **로그인**
   - 첫 화면에서 이름을 입력하여 로그인
   - 처음 입력하는 이름이면 자동으로 계정 생성

2. **대시보드**
   - 로그인 후 자신에게 배정된 점포 목록 확인
   - 각 점포의 진행률(완료된 체크 항목 비율) 확인
   - 점포 카드를 클릭하여 상세 페이지로 이동

3. **점포 상세 페이지**
   - 점포 정보 확인 (이름, 주소, 카테고리 등)
   - "지도에서 보기" 버튼으로 위치 확인
   - 체크리스트 항목별로 체크/언체크
   - 각 항목에 메모 추가 가능
   - 카테고리별로 구분된 체크리스트

### 관리자

1. **관리자 페이지 접속**
   - http://localhost:3000/admin 으로 접속

2. **점포 추가**
   - 점포 번호 (1-44)
   - 점포명
   - 주소
   - 지도 링크 (네이버 지도, 구글 지도 등)
   - 카테고리 (선택사항)
   - 추가 정보 (선택사항)

3. **체크 항목 추가**
   - 항목명 (필수)
   - 설명 (선택사항)
   - 카테고리 (예: "사전 준비", "현장 확인" 등)
   - 순서 (표시 순서를 정하는 숫자)

4. **점포 할당**
   - 스태프 선택
   - 점포 선택
   - "점포 할당" 버튼 클릭

## 📊 데이터베이스 구조

### Staff (스태프)
- 이름 (고유값)
- 생성일

### Store (점포)
- 점포 번호 (1-44, 고유값)
- 점포명
- 주소
- 지도 링크
- 카테고리
- 추가 정보

### CheckItem (체크 항목)
- 제목
- 설명
- 카테고리
- 표시 순서

### StoreAssignment (점포 할당)
- 스태프 ID
- 점포 ID
- 할당 날짜

### ChecklistEntry (체크리스트 엔트리)
- 스태프 ID
- 점포 ID
- 체크 항목 ID
- 체크 여부
- 메모
- 체크 시간
